# 🧮 Python Calculator

A simple yet flexible command‑line calculator written in Python. It supports basic arithmetic operations, exponentiation, and square roots, with input validation and a history of all results.

## ✨ Features

- **Basic operations**: Addition (`+`), subtraction (`-`), multiplication (`*`), division (`/`).
- **Advanced operations**: Exponentiation (`**`), square root (`s`).
- **Square root choice**: When using `s`, you can choose to take the square root of either the first or the second number.
- **Input validation**: Prevents crashes from non‑numeric input and division by zero. Negative numbers are blocked for square root.
- **Result history**: All calculations are stored in a list and displayed at the end of the session.
- **Repeat loop**: Perform multiple calculations in one session without restarting.

## 📦 Requirements

- Python 3.6 or higher.
- No external libraries – uses only the built‑in `math` module.

## 🛠️ How to Run

1. Clone this repository or download the script.
2. Open a terminal in the project folder.
3. Run the script:
   ```bash
   python calculator.py
