\# 📓 Console Diary



A simple command-line diary written in Python.  

Add timestamped notes, view all entries, and search by keyword.  

All data is stored in a plain text file (`diary.txt`).



\## ✨ Features



\- \*\*Add entries\*\* – each note is saved with the current date and time (`YYYY-MM-DD HH:MM`).

\- \*\*View all notes\*\* – numbered list of everything you’ve written.

\- \*\*Search\*\* – find entries containing a specific word (case‑insensitive).

\- \*\*Persistent storage\*\* – the diary file is automatically created and appended to.



\## 🚀 How to Run



1\. Make sure you have Python 3.6 or higher installed.

2\. Clone the repository or download the script.

3\. Run the program:



&#x20;  ```bash

&#x20;  python diary.py
