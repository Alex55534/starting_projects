\# 📊 Console Text Analyzer



A simple Python program for working with a text file: reading, writing, and counting letters and words.



\## ✨ Features



\- \*\*Read text\*\* – display the entire contents of the file.

\- \*\*Add text\*\* – append new lines to the end of the file.

\- \*\*Count letters\*\* – total number of alphabetic characters (Latin and Cyrillic; numbers and punctuation excluded).

\- \*\*Count words\*\* – total number of words in the file.



All data is stored in the `analyz.txt` file, located in the same folder as the script.



\## 🚀 How to Run



1\. Make sure you have Python 3.6 or higher installed.

2\. Clone the repository or download the script.

3\. Place (or create an empty) `analyz.txt` in the same folder.

4\. Run the script:



&#x20;  ```bash

&#x20;  python analyzer.py
