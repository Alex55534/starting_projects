\# 🐍 My Python Learning Projects



A portfolio of programs written while learning Python.



\## 📁 Project List

\- 🧮 \*\*Calculator\*\* – 6 operations, history, error protection

\- 🎲 \*\*Guess the Number\*\* – game with hints and attempt counting

\- 🔐 \*\*Password Generator\*\* – random passwords with character selection

\- 🪢 \*\*Hangman\*\* – text game in Russian and English

\- 💱 \*\*Currency Converter\*\* – conversion with fixed exchange rates

\- 📋 \*\*To-Do List\*\* – tasks saved to a text file

\- 📊 \*\*Text Analyzer\*\* – counting letters and words



Each project is in its own folder with a separate README.
